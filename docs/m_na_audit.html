N/A audit: Grad-CAM, attention rollout, VIPER

Selvaraju 2017; Abnar & Zuidema 2020; Bastani 2018

← back to the method catalogue

What it does?

This entry is an honesty audit, not a method that runs. Three well-known techniques, Grad-CAM, attention rollout, and VIPER, cannot be applied to the VCS at all, and we record that fact rather than force a number. Grad-CAM weights the final convolutional feature maps of a network by the gradient of the class score, so it needs a convolutional layer that the VCS does not have. Attention rollout multiplies the attention matrices across a transformer's layers, so it needs attention weights that the VCS does not have. VIPER distils a learned policy into a decision tree, so it needs a trained policy, and the VCS runs a fixed ROM, not a learned agent. The VCS is a 6502 CPU with a TIA video chip and a RIOT, executing hand-written machine code. Across all 42 scored games the count of each required substrate, convolutional layer, attention matrix, learned policy, is exactly zero. Re-targeting Grad-CAM's pooling onto the raw register state would simply be the content-path gradient under a different name, so it would add nothing. We therefore mark these methods as 'does not apply', a structural absence that is the same in every game. Recording this openly is part of the audit: it shows that some popular tools have no purchase on a real artifact that lacks the structure they assume.

The idea in plain words

Every XAI method is a recipe, and every recipe has ingredients. Saliency needs a differentiable function. Occlusion needs a way to blank out an input. Some popular methods need much more specific ingredients: a convolutional layer whose feature maps can be weighted, attention matrices that can be multiplied together, or a trained agent whose behaviour can be copied. If the system you study lacks the ingredient, the recipe cannot even start. That is what applicability means. A method applies to a system only if every object its formula refers to actually exists there, and every assumption behind its interpretation holds.

The Atari 2600 VCS is a hand-written program on a 1977 games console. It has a CPU, a video chip and a timer chip. It has no neurons, no layers, no attention and no learned agent. So some famous methods simply have nothing to bind to. This page is an audit of those methods. We do not invent a stand-in and report a score for it. We record “does not apply”, name the missing ingredient, and explain why every stand-in we could build would be a different method under a borrowed name. An empty cell in a results table is more honest than a number that measures nothing.

How it works on a neural network

Here are the three flagship methods of the audit, and exactly what each one needs on a network.

Grad-CAM (Selvaraju et al. 2017). Take the last convolutional layer: \(K\) feature maps \(A^k\), each a small grid of activations. Average the gradient of the class score \(y^c\) over each map to get one weight per channel, then form a ReLU-ed weighted sum:

\[ \alpha_k^c = \frac{1}{Z}\sum_{i,j}\frac{\partial y^c}{\partial A^k_{ij}}, \qquad L^c = \mathrm{ReLU}\Big(\sum_k \alpha_k^c A^k\Big) . \]

Ingredients: learned channels \(k\), a spatial grid \((i,j)\) aligned with the image, and a class score. CAM, Grad-CAM++ and feature visualisation / TCAV (concept vectors in a learned activation space) need the same kind of learned, spatially arranged channels.

Attention rollout (Abnar & Zuidema 2020). A transformer layer \(l\) has an attention matrix \(A^{(l)}\): how much each token reads from each other token. Mix in the residual connection and multiply through the layers:

\[ \tilde A^{(l)} = \tfrac12 A^{(l)} + \tfrac12 I, \qquad R = \tilde A^{(L)}\cdots\tilde A^{(1)} . \]

Ingredients: tokens and softmax attention weights in every layer.

VIPER (Bastani et al. 2018). Take a trained reinforcement-learning policy \(\pi(a\mid s)\) with its Q-function (how good each action is in each state). Train a decision tree to imitate it, weighting states by how much a wrong action would cost. Ingredients: a learned policy and its Q-values.

Toy example: what a forced re-target produces. On a tiny CNN with two \(2\times2\) maps \(A^1=\begin{pmatrix}1&0\\0&0\end{pmatrix}\), \(A^2=\begin{pmatrix}0&2\\0&2\end{pmatrix}\) and channel weights \(\alpha_1=0.5\), \(\alpha_2=-0.25\), Grad-CAM gives \(L=\mathrm{ReLU}\begin{pmatrix}0.5&-0.5\\0&-0.5\end{pmatrix}=\begin{pmatrix}0.5&0\\0&0\end{pmatrix}\): one hot cell. Now try it on RAM. Suppose we declare the 128 bytes one “map” with one channel. Then \(\alpha\) is the mean gradient, and \(L_i=\mathrm{ReLU}(\alpha\,\mathrm{ram}_i)\) is just a rescaled copy of the RAM. It says nothing about which byte matters. Suppose instead each byte is its own \(1\times1\) channel. Then \(\alpha_k\,\mathrm{ram}_k = \frac{\partial y}{\partial \mathrm{ram}_k}\,\mathrm{ram}_k\), which is Gradient×Input, a method we already score. Either way the “Grad-CAM” label adds nothing.

Recipe

  1. Write down the method's formula and list every object it refers to (feature maps, attention matrices, a policy, learned directions).
  2. Check each object against the system. Does it exist? Is it learned, so that the method's interpretation makes sense?
  3. If one is missing, look for a faithful substitute. Would the method's defining steps still mean what they mean on a network?
  4. If the only substitutes collapse into another method (or into the ground truth itself), record does not apply and the missing ingredient.
  5. Contrast with methods that do apply: confirm they have real causes to work on, so the absence is structural, not a coverage gap.
  6. Keep the n/a row out of the faithfulness leaderboard rather than giving it a zero or an invented score.

From a neural network to the Atari

Convolutional feature maps \(A^k\) (Grad-CAM, Grad-CAM++, CAM)None. The VCS has no learned intermediate layers. The TIA (video chip) draws pixels directly from register values set by hand-written code, line by line.
Attention matrices \(A^{(l)}\) (attention rollout)None. Which byte influences which is fixed by the program's instructions. That true data flow is what the intervention oracle and path patching measure; calling it “attention” would relabel ground truth as a method.
A learned policy \(\pi(a\mid s)\) (VIPER)None. The study explains the console itself. Joystick inputs come from a seeded random stream, not from a trained agent.
Learned channels / concepts (feature visualisation, TCAV)None. RAM bytes and registers have fixed, known meanings (the score byte is the score). Testing such meanings is the job of probing with control tasks.
A ground truth to score againstPresent: the intervention oracle and many candidate causes per game. The applicable methods use them; the n/a methods produce no map to compare.

How we apply it to the VCS

The audit is a runner like every other, na_audit.jl, but it runs no method, because there is nothing to run. Instead it writes a structured, checkable record.

  • Six audited methods. NA_METHODS lists Grad-CAM, Grad-CAM++, attention rollout, VIPER, CAM, and feature visualisation / TCAV. Each entry names the required ingredient, its kind (conv feature maps, attention, learned policy, learned channels), sets present_in_vcs = false, and gives two texts. One says why the method does not apply. The other says why a naive re-target onto VCS state would be a different method.
  • Grounding per game. ground_game loads the game's candidate-cause file: the RAM bytes the applicable methods attribute over. It records that count next to zero conv maps, zero attention heads, zero learned policies and zero learned channels. That asymmetry is the finding: there are real causes to explain, and none of the ingredients these methods need.
  • The contrast. APPLICABLE_CONTRAST names methods that do bind to real causes: vanilla gradient, Integrated Gradients, occlusion, counterfactuals. They are scored against the same oracle (run_intervention) elsewhere, and gradient methods flow through soft_ram_peek. A re-targeted Grad-CAM would collapse onto exactly those gradients.
  • A self-check. selftest asserts that every entry is marked absent with a named ingredient, that the canonical methods are covered, that every core game has candidate causes, and that the record round-trips. The headline value is the count of methods that do not apply; the record carries no F, S or M.

Why not force a number? Any score needs a map to compare with the oracle. Building one would mean choosing a stand-in for the missing ingredient, and every stand-in we can build is either uninformative (the rescaled-input case above), a method already on the leaderboard (Gradient×Input), or the ground truth itself (the data-flow graph). Scoring it under the famous name would credit or blame that method for something it never did. The absence is also structural. It is the same in every game, because no cartridge contains a network. That is why the record is game-independent and why it stays off the leaderboard.

Reading the result

This page has no faithfulness figure, and that is the point. The audit box marks the row as excluded from the leaderboard and shows how many methods were audited. Read the per-method table as a list of preconditions: for each method, the ingredient it needs, the fact that the VCS has none of it, and the reason a substitute would not be the same method. The same verdict holds for every game. Set it beside the gradient and perturbation pages: those methods need only a function and a way to change its inputs, and both exist on the VCS.

Pitfalls

  • Forcing a method produces a different method. Re-targeting Grad-CAM onto raw state yields a rescaled input or Gradient×Input. Reporting it as “Grad-CAM” misattributes the result.
  • A zero is not the same as n/a. Entering a score of 0 would claim the method ran and failed. Leaving the row out of the leaderboard records that it could not run.
  • Applicability is about meaning, not just shapes. You can reshape 128 bytes into an 8×16 grid, but neighbouring bytes are not neighbouring pixels. Grad-CAM's spatial reading assumes a grid that comes from the image.
  • Attention is not explanation anyway. Even where attention exists, its weights may not reflect what drives the output (Jain & Wallace 2019). Applicability is a necessary condition, not a guarantee.
  • The verdict is scoped. These methods do apply to a neural agent playing Atari. The audit concerns the console itself, which is the subject of this study.

How it's scored

This entry is not scored on the faithfulness leaderboard, and that is deliberate. Grad-CAM, attention rollout, and VIPER need a convolutional layer, an attention matrix, or a learned policy that the VCS does not have. Across all 42 scored games the count of each required substrate is exactly zero, against many genuine candidate causes per game for the methods that do apply. A faithfulness number would be meaningless, because there is no map to compare to the oracle. So we record a measured structural fact, applies equals false, rather than force a score. We also note that re-targeting Grad-CAM's pooling onto the raw register state would only be the content-path gradient under another name, so it would add no new information. The grading standard elsewhere in the audit is always correlation, F1, or effect-agreement against the intervention oracle; here none of those is defined, because the method cannot run. The audit box below therefore marks this row as excluded from the leaderboard rather than showing an F, S, and M triad. Recording the absence openly is itself a finding: several popular tools have no purchase on a real artifact that lacks the neural structure they assume.

The score is measured against the §1 intervention oracle — never against another interpretability method. F (faithful) is always vs the oracle; see the execution stack.
