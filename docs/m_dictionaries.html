NMF/PCA dictionaries

—

← back to the method catalogue

What it does?

Dictionary learning with NMF or PCA is a simpler cousin of the sparse autoencoder. It decomposes the recorded state into a small dictionary of components: PCA finds orthogonal directions of largest variance, NMF finds additive, non-negative parts. Each component is then matched to a known variable, on the hope that the decomposition recovers the machine's true internal factors without supervision. This is a classic, cheap way to look for structure in high-dimensional activity, and it predates the neural sparse-autoencoder approach. We run it on the VCS state and measure the fraction of dictionary components that match a known, verified variable. It does partially well: NMF's non-negativity separates the additive register basis better than PCA, which tends to mix several variables into one component. So NMF recovers cleaner named components while PCA blurs them. The deeper limit is the same one that defeats the sparse autoencoder. A component can match a variable by correlation while playing little causal role, so a good matched fraction does not guarantee the component is causally used. The VCS lets us check both the match and the causal use, and the two often disagree. Dictionary learning is thus a useful, interpretable baseline whose named components must still be tested by intervention before they can be trusted.

The idea in plain words

Suppose you record a network's activations for thousands of inputs and stack them into one big table: one row per input, one column per neuron. A dictionary is a short list of “building-block” patterns, called atoms or components, such that every row can be written as a weighted sum of a few atoms. If the atoms line up with real concepts, you have found the concepts without any labels. This is dictionary learning, and it is much older than deep learning: neuroscientists used it in the 1990s to explain how the visual cortex codes images.

Two classical recipes are fast and need no training loop. PCA (principal component analysis) finds the directions along which the data varies most; they are orthogonal and may have negative entries. NMF (non-negative matrix factorisation) only allows non-negative atoms and weights, so everything is built by adding parts, never by cancelling them. That often gives “parts” a human can recognise. The sparse autoencoder is the modern, learned, sparse member of the same family. Running the classical ones first shows how much the extra machinery buys.

How it works on a neural network

Put the data in a matrix \(X\) with \(T\) rows (samples) and \(n\) columns (neurons). Both methods approximate it by a product of a thin matrix of activations \(A\) (\(T\times r\)) and a short matrix of atoms \(H\) (\(r\times n\)), with \(r \ll n\):

\[ X \;\approx\; \mu + A H \quad(\text{PCA, } H H^\top = I), \qquad X \;\approx\; A H \quad(\text{NMF, } A \ge 0,\ H \ge 0). \]

PCA takes \(\mu\) = the column means and \(H\) = the top \(r\) right singular vectors of the centred data. NMF minimises \(\|X - AH\|^2\) with the Lee–Seung multiplicative updates, which keep every entry non-negative. An SAE is the same picture with a learned, non-linear, sparse encoder for \(A\).

Toy example. Three RAM-like cells \((a, b, c)\). Cells \(a, b\) move together (a ball's x and a copy of it); cell \(c\) is a score. Four frames: \((4,2,0)\), \((2,1,0)\), \((0,0,5)\), \((4,2,5)\). NMF with \(r=2\) finds the exact answer \(H_1=(2,1,0)\) (“ball”), \(H_2=(0,0,1)\) (“score”), with weights \((2,0), (1,0), (0,5), (2,5)\). Each atom is one variable. PCA on the same data gives a first component of roughly \(0.92\cdot\)score \(-\,0.38\cdot\)ball: both variables vary a lot, so the direction of largest variance mixes them, with a sign. Same data, same rank; only the constraint differs.

Recipe

  1. Record many activation vectors and stack them into a samples × units matrix.
  2. Choose the number of atoms \(r\) (try several).
  3. Fit PCA (singular value decomposition of the centred matrix) and NMF (multiplicative updates on the raw, non-negative matrix).
  4. Inspect each atom's loadings: which units does it weigh, and do they belong to one concept?
  5. Count the share of atoms that match a known concept (the matched fraction).
  6. Test causally: remove one atom from the reconstruction, put the state back into the model, and measure the change in output.

How we apply it to the VCS

Our runner dictionaries.jl applies PCA, NMF and a small sparse autoencoder to the same RAM tape and scores all three with the same tests. That makes it a fair three-way comparison.

  • Data. The RAM after each frame along the shared gameplay stream (90 seeded random-action frames, the 15-frame horizon, then NOOP; 150 frames for Pong). PCA uses the centred bytes. NMF uses the raw bytes, which are naturally non-negative (0–255). The SAE uses z-scored bytes.
  • Models. PCA is one singular value decomposition. NMF runs 300 Lee–Seung updates. The SAE has as many hidden units as the rank, L1 weight 0.05, and 3000 epochs of gradient descent. All three are run at ranks 8, 4 and 12; rank 8 is the headline.
  • Matching. An atom counts as matched to a game variable if at least a quarter of its squared loading mass sits on candidate cells and at least half of that mass sits on one concept family. Otherwise it can still be matched to a structural signal if its activation over time correlates with the frame clock, the per-frame change count, or the periodic phase at \(|r|\ge 0.5\). The matched fraction is matched atoms over all atoms.
  • Causal use. The RAM at \(f^*\) is projected onto the dictionary. For each atom we zero its weight, decode, round and clamp to bytes, write all 128 bytes into a copy of the machine, and play the 15-frame tail. The effect is the number of screen pixels that differ from the same write without the ablation, so the lossy reconstruction does not count as an effect. The same ablation is also played under a different, held-out action tail.
  • Positive control. Zeroing all atoms must break the screen. Otherwise the causal test would be blind.

The triad: F is the Spearman correlation between how strongly each atom matches a variable and its causal effect (“are the named atoms the used ones?”). S correlates the effect with the held-out-tail effect. M is one minus the share of matched atoms whose removal does nothing: naming a causally dead atom is an over-claim.

Why NMF tends to win on the VCS: RAM is literally a list of separate bytes that the program adds to and overwrites. That is an additive, non-negative “parts” structure, which is what NMF assumes. PCA's orthogonality has no reason to hold, so its components blend variables that happen to vary together.

Reading the result

The figure compares the matched fraction of PCA, NMF and the SAE. Expect a partial result: NMF recovers more cleanly named atoms than PCA, because its atoms are additive parts, while PCA folds several variables into one signed direction. Then look at causal use. Several matched atoms do little or nothing when removed, while some unmatched ones matter. So a good matched fraction is evidence that a variable is present in the data, not that the program uses that atom. This is the same gap the SAE page shows.

Pitfalls

  • Variance is not importance. PCA ranks directions by how much they vary. A busy frame counter can dominate the first component while a rarely changing but crucial byte is buried.
  • The rank is a choice. Too few atoms merge variables; too many split one variable over several atoms. We sweep ranks 4, 8 and 12 for this reason.
  • Unsupervised factors are not unique. Locatello et al. proved that, without extra assumptions, many different factorisations explain the data equally well. A matching atom may be luck of the initialisation.
  • Rounding to bytes. On the VCS a decoded state must be rounded to integers before it can be written. Small atoms can vanish in the rounding, which reads as “no causal effect”.

How it's scored

The score is the fraction of NMF or PCA dictionary components that match a known, verified variable. We decompose the state into a small dictionary, match each component to a known variable, and count the matched fraction. The grading is always against the intervention oracle. Faithfulness for this method is that matched fraction, and it is partial: NMF's non-negativity separates the additive register basis better than PCA, so NMF yields cleaner named components while PCA blurs several variables into one component. The deeper limit, which the matched fraction alone does not expose, is causal use. A component can match a variable by correlation while playing little causal role, so a good matched fraction sits beside near-zero causal use, exactly as it does for the sparse autoencoder. There is no sprite-position hard-case here; the output is a set of components. The grading is always against the oracle, never against another method. The audit box reports the measured triad across the scored games, so the matched fraction is an average over the scored set. Dictionary learning is a useful interpretable baseline, but its named components must be tested by intervention before they can be trusted, and the score reflects that gap.

The score is measured against the §1 intervention oracle — never against another interpretability method. F (faithful) is always vs the oracle; see the execution stack. How each of F / S / M is actually computed for this method (and whether it matches the paper) is in the box just below; the numbers are in the In the audit box under it.

content-F and position-F are n/a for this method. The content-vs-position split applies only to pixel-attribution methods — those that produce an attribution map over the framebuffer, whose score can be read separately on the smooth content outputs and the discrete position outputs (where the naive gradient is provably zero). This method does not attribute to a pixel output; it is graded by its own fidelity metric (nmf_causal_effect_agreement_spearman), reported as the F column, so there is no content or position regime to separate.

S is negative on 8 of these games. Sufficiency asks whether the explanation can predict the outcome of held-out interventions it was not fit on; for this method S is the held-out predictive correlation between its claim and the true effect, so it lies in [−1, 1]. A value near 0 means the explanation predicts no better than the unperturbed output; a negative value means it predicts worse — its held-out claim is anti-correlated with the truth (named yet causally unused).
